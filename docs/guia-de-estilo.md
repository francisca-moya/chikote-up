# Guía de estilo - Chikote Up
## Las buenas ideas van a fuego lento

Este documento recoge las directrices visuales de Chikote Up y establece los criterios de uso de sus elementos gráficos, colores y tipografías, con el objetivo de mantener una identidad visual coherente en toda la aplicación.

### Logotipo

Pendiente de diseño

### Paleta cromática

  - `#3B2A22` Marrón oscuro  -> Texto principal, títulos, iconos
  - `#FFF8F0` Crema          -> Fondo general de la web
  - `#ED8E8E` Coral          -> Botones, acentos, elementos destacados
  - `#EDC08E` Ocre suave     -> Fondos secundarios, tarjetas, detalles

### Tipografía

  - Chau Philomene One  -> Títulos y encabezados principales
  - Alegreya Sans       -> Subtítulos y encabezados secundarios
  - Balsamiq Sans       -> Párrafos, descripciones y textos generales

### Variables CSS

```css
:root {
  /* Paleta cromática */
  --marron-oscuro: #3B2A22;
  --crema: #FFF8F0;
  --coral: #ED8E8E;
  --ocre-suave: #EDC08E;

  /* Tipografía */
  --fuente-titulo: "Chau Philomene One", cursive;
  --fuente-subtitulo: "Alegreya Sans", sans-serif;
  --fuente-texto: "Balsamiq Sans", sans-serif;
}
```
